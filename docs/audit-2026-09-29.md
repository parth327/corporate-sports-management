## Mock API (the backend stand-in)

| # | Severity | Root cause | Resolution | Verified by |
| --- | --- | --- | --- | --- |
| A1 | Medium | **N+1 lookups.** `findById` scanned the whole table; list decoration re-scanned child tables for every row (`allocatedCount`, `teamCount`, `umpireIds`), so a list cost O(rows × table). | Primary-key index per collection (`byId` in `db.ts`, invalidated by array identity + length — rows are only appended or the array replaced). | A2 | High | **Session forgotten after a reload.** `/api/account/me`, `/profile` and `/logout` read module state (`currentUser`), which a reload wipes, instead of recovering the session from the token like every other route. ## Independent review follow-up (2026-09-30)

A reviewer with no part in the audit re-read the changed code for defects. All
twelve findings held up against the code and are fixed. The suite is now
**75 / 75**, including the team-builder lab added the same day. Suite checks named below follow the reviewer's reproduction steps; unlike the regression checks above, they were not re-run against the pre-fix code.

## Added

- **Procedural 3D stadium** (`src/three/stadium/`): instanced crowd with a
  travelling wave, stands sized by Colour League points, shader-drawn pitch with
  computed floodlight pools, LED boards, floodlight towers with light shafts,
  night sky, plaza and car parks. Fifteen draw calls, no real-time lights, no
  textures or models to download.
- **Scroll narrative:** ten camera shots anchored to the page's sections, a
  damped spline camera, pointer parallax, an opening dolly, a chapter rail, and
  section-driven colour.
- **Lenis** smooth scrolling (wheel only; native touch), with in-page links that
  animate and hand focus to their section, paused while overlays are open, and
  off under reduced motion.
- **Adaptive quality:** device profiles plus runtime pixel-ratio stepping; CSS
  stand-in stadium while loading or without WebGL2.
- **Fluid layout to 4K:** wider shell at 1920 and 2560 px, and rem scaling on
  the public site only.

## Not verifiable here

- Frame rates on real phones: measured on an integrated desktop GPU with phone
  viewports and settings, not on handset GPUs.
- Safari and Firefox were not run; everything was exercised in Chrome.
- The ASP.NET API is not in this repository; the mock enforces the same rules,
  and fixes A2–A3 describe behaviour the real API must match.
